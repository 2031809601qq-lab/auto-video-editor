# 自动话题剪辑工具（精简版）

Windows 上的本地 FFmpeg 话题剪辑工具，包含表格界面、按计划切片和拼接、话题文件夹及文字说明，以及手机与电脑的局域网视频互传。

## 使用

1. 安装 FFmpeg，确保 `ffmpeg` 和 `ffprobe` 都能在 PATH 找到；手机互传还需要 Node.js。
2. 双击“启动FFmpeg剪辑界面.bat”。在表格里填写话题、标题、素材文件名、开始及结束秒数、说明；同一话题和标题的多行按顺序拼接。先在“剪辑计划”填写 JSON 保存路径，点击“保存计划”，然后选择素材目录和成品目录并开始剪辑。
3. 默认导出竖屏 1080×1920、60 fps 的 H.264 MP4，保留原声音轨，不自动添加配乐。每个话题生成子文件夹、视频和文字说明，另生成成片索引。
4. 双击“启动手机电脑视频互传.bat”，根据电脑显示的地址和访问码，在同一局域网的手机浏览器中访问。详细说明见 `工具/手机互传/使用说明.md`。

## 命令行

参照 `工具/剪辑计划模板.json` 编写计划。`segments` 的顺序就是最终播放顺序；若需要前三秒钩子，先人工选择完整、有吸引力的原片片段，作为第一段，然后安排原因和上下文，并检查结尾是否完整。

```powershell
& '.\工具\Invoke-TopicEdit.ps1' -Plan '.\工具\剪辑计划模板.json' -Sources '.\素材' -Output '.\成品'
```

支持 `-Width`、`-Height`、`-Fps`、`-Ffmpeg`、`-Ffprobe`、`-Encoder` 等参数；默认先尝试硬件编码，再使用 libx264。默认不覆盖已有视频，明确需要覆盖时使用 `-Overwrite`。

## 能力边界

该工具执行人工确认的时间点，不会自动理解内容、识别话题或空镜、生成钩子、匹配动效和校对字幕。转写、画面分析、切点和文案需要单独完成并审听。开拍的自动导入还未验证，不包含在此版本中。

手机互传是局域网服务，仅适合可信网络；使用动态访问码，通过 HTTP 传输。运行时生成的访问地址和素材、成品不会纳入仓库。

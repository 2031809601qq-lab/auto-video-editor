# 手机和电脑互传视频

电脑需要安装 Node.js。双击项目根目录的“启动手机电脑视频互传.bat”，电脑会启动一个局域网网页，并打开包含访问地址和一次性访问码的记事本。

手机与电脑连接同一个 Wi-Fi 后，在手机浏览器输入记事本里的局域网地址，再输入访问码。页面可以把手机视频上传到 `素材\手机传入`，也可以播放或下载 `成品` 文件夹里的视频。一次可选多个文件，上传显示进度，同名文件会自动改名保留。

传输期间电脑要保持开机并运行服务窗口。关闭服务窗口会停止共享。Windows 防火墙若询问，请允许 Node.js 在专用网络通信。手机不用安装 App。

访问码每次启动时重新生成。此服务仅供同一 Wi-Fi 内使用，不要将 8765 端口转发到公网。电脑如未安装 Node.js，需先安装再启动。

无法访问时，确认手机与电脑在同一 Wi-Fi，并尝试记事本中的 `192.168` 地址。部分访客 Wi-Fi 会隔离设备，这种情况下可以让两台设备连入同一手机热点。

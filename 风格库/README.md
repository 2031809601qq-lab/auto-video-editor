# 参考视频与剪辑风格库

每新增一条模仿视频，复制 `模板.md` 建一份记录，按 `类型/序号_名称.md` 保存。记录原片位置、画幅、时长、前三秒钩子、节奏、字幕、动效、转场、音效、适用话题和不适用场景。引用原片时只记录相对路径与时间码，不把视频文件上传到仓库。

完成仿剪后追加“使用记录”：关联成片、哪些手法实际采用、人工审看发现的问题、下一版改动。相同风格可复用镜头规则，但每条视频都应按内容重新选择钩子与转折点。

当前有一条已分析的竖屏口播参考，见 `口播/001_固定标题与关键词字幕.md`。以后收到新参考时先分类，再登记，不直接覆盖旧记录。

室内口播的本地精修实操参数与问题复盘，见 `口播/002_室内人脸精修与气口处理.md`。
